# AI Usage Report

## AI Tool Used
I used ChatGPT as an AI assistant while working on this assignment. I mainly used it for guidance, checking parts of my code, and getting suggestions when I was unsure about something.

## How I Used AI
I used ChatGPT to help me check the structure of my HTML and CSS and to make sure I was following the assignment requirements. I also asked for help understanding syntax and responsive design and choosing a simple JavaScript feature for the website.

I decided to use a greeting that changes based on the current time. I reviewed the JavaScript and made sure I understood how it gets the current hour and uses conditions to display the correct greeting.

## Benefits and Challenges
One benefit of using AI was that I could ask questions when I was unsure about my code and get explanations quickly. It also helped me notice small issues and check whether I was meeting the requirements.

A challenge was deciding which suggestions actually fit my website. Some suggestions could make the project more complicated than needed, so I kept the design and features simple and only used ideas that I understood and found useful.

## Learning Outcomes
While working on this assignment, I improved my understanding of organizing an HTML page, using Flexbox, and using media queries to make a website responsive. I also learned how JavaScript can use the current time to change content on a webpage.

I also became more comfortable organizing a project into separate HTML, CSS, JavaScript, image, and documentation files.

## Responsible Use and Modifications
I reviewed the AI-generated suggestions before using them and modified them to fit my own website. I also tested the changes myself to make sure they worked correctly and made further adjustments and improvements when needed.

For example, I changed the placement of the greeting and tried different image sizes and alignment before choosing what worked better with my design. I also tested the responsive layout by resizing the browser and adjusted the website based on what I observed. The portfolio content, projects, interests, and images were chosen by me. By reviewing, modifying, and testing the suggestions, I made sure the final work showed my own decisions and improvements while using AI responsibly.
