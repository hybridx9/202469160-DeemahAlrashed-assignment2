# AI Usage Report

## AI Tool Used

I used ChatGPT as an AI assistant while working on this assignment. I mainly used it for guidance, explanations, code suggestions, and checking that I was following the assignment requirements.

## How I Used AI

I used ChatGPT to help me understand how to add interactive features to my existing portfolio. I asked for suggestions on implementing a Show More / Show Less button, validating the contact form using JavaScript, and adding simple CSS transitions.

I also used ChatGPT to check the implementation and understand how the JavaScript responds to user actions, checks form inputs, and displays feedback messages.

## Benefits and Challenges

One benefit of using AI was getting explanations and suggestions when I was unsure how to implement a feature. It also helped me check the requirements and understand how different parts of the code work together.

A challenge was deciding how to add the new features without making my existing website unnecessarily complicated. I wanted the changes to be useful and fit the design of my portfolio, so I focused on simple interactions that I could understand and test.

## Learning Outcomes

While working on this assignment, I improved my understanding of JavaScript event listeners and how they can respond to user actions. I also learned how to validate form inputs, display feedback messages, and use CSS transitions to make interactions smoother.

I gained more experience testing interactive features and checking how changes affect the website on different screen sizes.

## Responsible Use and Modifications

I used the AI suggestions as a starting point and adjusted the implementation to fit my existing portfolio. I chose to display more information about my interests and goals in the About Me section and decided to improve my existing contact form instead of adding an unrelated feature.

I also adjusted the HTML structure to include the new interactive elements, added comments to explain the code, and kept the CSS changes consistent with my original design. After implementing the features, I tested the Show More / Show Less button, tried different form inputs to check the validation and feedback messages, and checked the hover transitions and responsive layout.

These decisions, modifications, and tests helped me understand the code better and improve my website while using AI as a learning tool.
