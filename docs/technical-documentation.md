# Technical Documentation

## Project Overview
This project is a personal portfolio website created using HTML, CSS, and JavaScript. It includes information about me, my projects, my interests, and a contact form.

## Project Structure
`index.html` contains the main structure and content of the website.
`css/styles.css` contains the styling and responsive design.
`js/script.js` contains the JavaScript used for the greeting message.
`assets/images` contains the images used for the projects.
`docs` contains the project documentation.

## HTML
The website is divided into About Me, Projects, Interests, and Contact sections. Navigation links are used to move to each section of the page.

The Projects section contains two projects with a title, description, and image. The Contact section contains fields for name, email, and message.

## CSS and Responsive Design
CSS is used to style the page, project cards, navigation bar, contact form, and other elements. Flexbox is used for the navigation bar and the contact form.

Media queries are used to adjust the website for different screen sizes. The layout was tested by resizing the browser to check the website on desktop, tablet, and mobile sizes.

## JavaScript
JavaScript is used to display a greeting based on the current time. The script gets the current hour and displays "Good morning!", "Good afternoon!", or "Good evening!".

## Testing
I tested the website by opening it in the browser and checking the navigation, project images, contact form, and greeting message. I also resized the browser to make sure the content displays correctly on different screen sizes.
