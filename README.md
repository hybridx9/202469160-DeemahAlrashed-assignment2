# Personal Portfolio – Assignment 2

This is my personal portfolio website developed for Assignment 2. It builds on my Assignment 1 portfolio by adding interactive features and improving the user experience.

## Features

The website includes an About Me section, two projects with images, an Interests section, and a Contact section.

The About Me section has a Show More / Show Less button that displays additional information when clicked. The contact form uses JavaScript to validate user input and display feedback messages. The website also includes smooth hover transitions for buttons and project cards, along with a greeting based on the current time.

## Technologies Used

HTML, CSS, and JavaScript were used to develop the website.

## Setup

Clone or download this repository.

Open the project folder.

Open `index.html` in a web browser.
